# Europa 2026 ✈️

Itinerario de viaje: **29 de agosto al 12 de septiembre de 2026**.

## 🌐 Ver la página

Una vez configurado GitHub Pages, la página estará disponible en:  
`https://<tu-usuario>.github.io/Europa2026/`

## 🚀 Activar GitHub Pages

1. Ve a tu repositorio en GitHub
2. **Settings** → **Pages**
3. En *Source*, selecciona la rama `main` y carpeta `/ (root)`
4. Guarda — en un par de minutos estará publicado

## ✏️ Personalizar

Edita `index.html` para:
- Cambiar los nombres de ciudades en `<span class="city-tag">`
- Reemplazar los bloques `<div class="placeholder">` con actividades reales
- Actualizar horarios de vuelos
- Agregar fotos o enlaces de hoteles

## 📁 Estructura

```
Europa2026/
└── index.html   ← Todo en un solo archivo (CSS + JS inline)
```
